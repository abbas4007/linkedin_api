# پروژه جستجوی لینکدین

این پروژه رو برای مصاحبه فول استک نوشتم. یه اپلیکیشن ساده که توش میشه توی ۳۰۰ تا پروفایل لینکدین جستجو کرد و بر اساس مهارت، عنوان شغلی، شرکت و مکان فیلتر زد.

## تکنولوژی‌هایی که استفاده کردم

- جنگو و DRF برای ساخت API
- SQLite برای دیتابیس (برای این حجم داده کافی بود)
- Bootstrap برای فرانت‌اند
- یه سری تست هم نوشتم که کارکرد درست رو تضمین کنه

## چطور اجرا کنم؟

pip install -r requirements.txt

python manage.py migrate

python manage.py import_data data/test.txt

python manage.py runserver


۵. برو به آدرس `http://127.0.0.1:8000` و شروع کن به جستجو.

## ساختار پروژه

- `home/models.py`: مدل پروفایل که توش فیلدهای مختلف و یه فیلد search_text برای جستجو دارم.
- `home/services.py`: منطق جستجو اینجاست. با Q objects کار میکنه و کلمه کلیدی رو توی چند تا فیلد مختلف جستجو میکنه.
- `home/views.py`: دو تا ویو دارم. یکی برای صفحه اصلی (فرانت‌اند) و یکی برای API که جستجو رو انجام میده.
- `home/management/commands/import_data.py`: اسکریپت ایمپورت دیتا که فایل CSV رو میخونه و توی دیتابیس ذخیره میکنه.
- `home/tests.py`: چند تا تست ساده برای چک کردن عملکرد جستجو و فیلترها.

## چالش‌هایی که داشتم

- ایمپورت دیتا یه کم چالش بود چون فایل CSV یه سری فیلد JSONی داشت که باید درست parse میشدن.
- جستجوی فازی رو با Q objects پیاده کردم که قبلاً کمتر باهاش کار کرده بودم.
- تصمیم گرفتم از SQLite استفاده کنم چون برای ۳۰۰ رکورد کاملاً کافی بود و نیازی به نصب دیتابیس جداگانه نداشتم.

## چیزهایی که میشد بهتر کنم

- به جای جستجوی ساده، از Elasticsearch استفاده کنم (برای پروژه‌های بزرگتر).
- فیلترهای بیشتری مثل محدوده حقوق یا سال سابقه کار اضافه کنم.
- فرانت‌اند رو با React بنویسم (ولی من فقط بوت استرپ کار کردم اونو یکم یادم رفته).

## تست‌ها

چند تا تست نوشتم که سناریوهای مختلف رو چک کنه:
- جستجو با کلمه کلیدی
- فیلتر بر اساس مهارت
- فیلتر بر اساس عنوان شغلی
- جستجو با نتیجه خالی
- pagination

برای اجرای تست‌ها:
python manage.py test
